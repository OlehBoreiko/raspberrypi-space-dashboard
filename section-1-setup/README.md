# Section 1: Rapid Raspberry Pi Setup for Space Projects

Welcome to the first section of the course! 🚀

In this section, we quickly set up your Raspberry Pi to get it ready for building a real-time Space Dashboard.

You'll learn how to:

- Flash and configure Raspberry Pi OS Lite (64-bit) for remote development.
- Enable SSH and WiFi without connecting a monitor or keyboard.
- Set up remote coding with Visual Studio Code and the Remote SSH extension.
- Create a clean project workspace with a virtual environment (venv).
- Secure your API keys and sensitive data using `.env` files.
- Initialize Git and set up basic version control practices.

---

## 📦 Key Tools and Technologies

- Raspberry Pi OS Lite (64-bit)
- SSH
- Visual Studio Code + Remote SSH Extension
- Python 3 and venv
- Git and GitHub (optional)
